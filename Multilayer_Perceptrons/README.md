# Multilayer Perceptron (MLP)

This section contains my implementations and projects based on **Multilayer Perceptrons (MLPs)** using Python and TensorFlow/Keras.

## 📌 About

A Multilayer Perceptron is a type of **feedforward artificial neural network** consisting of multiple fully connected (Dense) layers.

MLPs are commonly used for tasks such as:

* Classification
* Regression
* Binary and Multiclass Prediction
* Tabular Data Modeling
